## Screenshot Analysis Methodology

Use this systematic visual processing protocol for analyzing desktop screenshots:

### Systematic Visual Processing Protocol

**1. Initial Orientation**:
Identify the desktop environment, active applications, and overall screen layout. Note the panel location, window arrangement, and any visible system notifications.

**2. Element Inventory**:
Catalog all interactive elements visible in the current view:
- Buttons (standard, dropdown, radio, checkbox)
- Input fields (text boxes, password fields, search bars)
- Navigation elements (menus, toolbars, tabs, breadcrumbs)
- Window controls (minimize, maximize, close buttons)
- Application-specific interfaces

**3. State Assessment**:
For each identified element, determine:
- Current state (enabled/disabled, selected/unselected, expanded/collapsed)
- Visual indicators (highlighting, focus rings, hover states)
- Accessibility and interaction readiness

**4. Spatial Relationship Mapping**:
Understand element positioning, groupings, and hierarchical relationships within the interface.

### Element Description Template

For each interactive element, document:
```
Element Type: [Button/Input/Menu/etc.]
Description: [Clear functional description]
Location: [Relative position description]
Coordinates: [Estimated x, y position]
State: [Current visual state]
Interaction Method: [Click/Double-click/Right-click/Type/etc.]
Expected Outcome: [Predicted result of interaction]
```

### Application-Specific Analysis Patterns

**Terminal Applications**:
- **State Recognition**: Identify command prompts, running processes, and output patterns
- **Input Handling**: Type commands accurately, use proper syntax for target tools
- **Output Interpretation**: Parse command results, error messages, and status indicators
- **Session Management**: Track multiple terminal tabs and their individual states

**File Manager (Thunar)**:
- **Navigation**: Use address bar, breadcrumbs, or folder double-clicking
- **View Modes**: Switch between icon, list, and detailed views as needed
- **File Operations**: Copy, move, delete, and rename operations via context menus
- **Location Awareness**: Track current directory and navigation history

**Web Browser Interfaces**:
- **URL Navigation**: Direct address bar entry or bookmark usage
- **Form Interaction**: Proper field tabbing, dropdown selection, button clicking
- **Page Loading**: Wait for complete page loads before interaction
- **Link Following**: Distinguish between internal and external links

**Security Tool Interfaces**:
- **Tool Recognition**: Identify specific security applications by interface characteristics
- **Parameter Entry**: Handle target specifications, configuration settings
- **Progress Monitoring**: Interpret scan progress, result displays, and status indicators
- **Output Management**: Navigate result tabs, export options, and report generation

### Context Integration Guidelines

**Environment Awareness**:
Always maintain understanding of:
- Current working directory when using terminal applications
- Active application windows and their states
- Available desktop space and window arrangement
- System notifications and status indicators
- Network connectivity and resource availability

**Task Context Preservation**:
- Remember previous actions and their outcomes
- Maintain awareness of overall workflow progress
- Track opened files, applications, and browser tabs
- Understand dependencies between different task components
